### Foundry：通过模板化 CUDA 图实现 LLM 推理服务的极速冷启动
- 原文标题: `Foundry: Template-Based CUDA Graph Context Materialization for Fast LLM Serving Cold Start`
- 来源: `arXiv cs.DC`
- 链接: [查看原文](https://arxiv.org/abs/2604.06664)
- 发布时间: `2026-04-09T04:00:00+00:00`
- 摘要: 针对 LLM 服务在自动扩缩容时 CUDA 图捕获（Capture）耗时过长（通常需数十秒）的问题，Foundry 提出了一种模板化持久化方案。它在离线阶段保存图拓扑和执行上下文，在线部署时通过确定性内存布局重建可执行图，实现近乎零开销的加载。
- 值得关注: 解决了 Serverless LLM 场景下冷启动的重大瓶颈，将启动耗时从分钟级降低到毫秒级，对高动态负载的推理基础设施至关重要。
- 标签: `LLM 推理, CUDA, 冷启动, 基础设施`

- 原文标题: `Nexus: Transparent I/O Offloading for High-Density Serverless Computing`
- 来源: `arXiv cs.DC`
- 链接: [查看原文](https://arxiv.org/abs/2604.06682)
- 发布时间: `2026-04-09T04:00:00+00:00`
- 摘要: Nexus 是一种基于 KVM 的新型 Hypervisor，通过零拷贝共享内存将 VM 内部沉重的通信栈（如 Cloud SDK、RPC、TCP/IP）透明地卸载到宿主机后端。这消除了每个函数实例中重复的 I/O 处理逻辑。

### ForkKV：利用写时复制技术实现多 LoRA 智能体的高效 KV 缓存共享
- 原文标题: `ForkKV: Scaling Multi-LoRA Agent Serving via Copy-on-Write Disaggregated KV Cache`
- 来源: `arXiv cs.DC`
- 链接: [查看原文](https://arxiv.org/abs/2604.06370)
- 发布时间: `2026-04-09T04:00:00+00:00`
- 摘要: 在多 LoRA 智能体协作场景中，不同 LoRA 权重会导致 KV 缓存发散。ForkKV 借鉴操作系统的 fork-with-copy-on-write 机制，将 KV 缓存解耦为大规模共享组件和轻量级智能体特定组件，并配合 DualRadixTree 架构进行管理。
- 值得关注: 显著降低了多智能体工作流的显存压力，解决了传统前缀缓存（Prefix Caching）在多 LoRA 环境下失效的问题。
